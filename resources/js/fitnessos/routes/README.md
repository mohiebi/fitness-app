# FitnessOS routes

These TanStack Router screens are bundled by Laravel Vite from `resources/js/fitnessos/main.tsx`.
Laravel serves their URLs from `routes/web.php` and protects `/dashboard/*` and `/app/*` by account role.

The route tree at `resources/js/fitnessos/routeTree.gen.ts` is generated by the TanStack Router Vite plugin. Do not edit it manually.

The public application and contact forms, lead board, client accounts, check-ins, and messages use Laravel endpoints under `/fitnessos/*`. Other imported screens still contain the original sample content and need product-specific backend work before launch.
